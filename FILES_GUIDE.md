# Project Files Guide

## Core Implementation Files

### `quantum_billiard.py` ⭐ (Main Implementation)
**Purpose**: Main quantum transport calculation code with SVG support

**Key Functions**:
- `parse_svg(svg_path)` - Parse SVG file and extract system geometry and leads
- `parse_path_to_pixels(path_data)` - Convert SVG paths to pixel coordinates
- `rasterize_line(p1, p2)` - Bresenham line rasterization
- `fill_polygon(vertices, boundary_pixels)` - Scanline polygon fill
- `make_system(params)` - Original parameter-based system construction
- `make_system_from_svg(svg_path, hopping, energy)` - NEW: SVG-based system construction
- `conductance_matrix(params)` - Calculate conductance matrix
- `main()` - Command-line interface with `--svg` support

**Usage**:
```bash
# With SVG
python quantum_billiard.py --svg system.svg --config parameters.toml --output data/conductance.npz

# Traditional mode
python quantum_billiard.py --config parameters.toml --output data/conductance.npz
```

### `parameters.toml` (Configuration File)
**Purpose**: Define simulation parameters

**Parameters**:
- `hopping`: Nearest-neighbor hopping strength (default: 1.0)
- `energy`: Fermi energy for transport calculation (default: 0.8)
- `length`, `width`, `lead_width`: Ignored when using `--svg` flag

**Example**:
```toml
[system]
hopping = 1.0
energy = 0.8
```

### `system.svg` (System Geometry)
**Purpose**: Defines the quantum system using visual elements

**Format**:
- Black (#000000): Main scattering region (quantum billiard)
- Blue (#0000FF): Semi-infinite leads (1D perfect channels)
- Coordinates in pixels (1px = 1 lattice site)

## Data Files

### `data/conductance.npz` (Output - Generated)
**Purpose**: Results from conductance calculation

**Contents** (after running quantum_billiard.py):
- `conductance`: 4×4 conductance matrix (units: e²/h)
- `lead_names`: Order of leads (["left", "right", "bottom", "top"])
- `parameters`: JSON string with simulation parameters

**Loading Results**:
```python
import numpy as np
data = np.load('data/conductance.npz', allow_pickle=True)
conductance_matrix = data['conductance']
lead_names = data['lead_names']
parameters = data['parameters']
```

## Workflow Summary

### Step 1: Prepare System
1. Create or edit `system.svg` with:
   - Black region for main billiard
   - Blue rectangles for leads
2. Ensure colors are exactly #000000 and #0000ff
3. Use pixel coordinates (1px = 1 site)

### Step 2: Configure
Edit `parameters.toml`:
```toml
[system]
hopping = 1.0      # Adjust as needed
energy = 0.8       # Adjust as needed
```

### Step 3: Validate (Optional)
```bash
python test_system_parsing.py
# Check console output and system_analysis.json
```

### Step 4: Calculate
```bash
python quantum_billiard.py --svg system.svg --output data/conductance.npz
```

### Step 5: Analyze
```bash
# View results (in Python)
import numpy as np
data = np.load('data/conductance.npz', allow_pickle=True)
print(data['conductance'])
```

## Important Notes

### Color Requirements
- **Black**: Must be exactly #000000 (not #333333 or other shades)
- **Blue**: Must be exactly #0000ff (not #0066ff or other shades)

### Coordinate System
- SVG viewBox and coordinates directly map to lattice sites
- Each pixel = 1 site in tight-binding model
- Coordinates automatically normalized to start from (0, 0)

### Lead Requirements
- Must be rectangular (rectangular leads detected by width > height or vice versa)
- Should overlap or touch main system for proper connection
- Periodicity is defined by shorter dimension of rectangle

### Output Format
- Conductance matrix: G[i,j] = transmission from lead i to lead j
- Diagonal elements: Reflection (should be ~0 for ballistic transport)
- Units: e²/h (quantum of conductance)
- Lead order: [left, right, bottom, top] or as defined in parsing
